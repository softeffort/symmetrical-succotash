ULTRA-МОДЕЛИ ЗА КРЕДИТЫ (2026-11-16)
===================================

Что это
-------
Ultra-модели (например, Claude) доступны только на тарифе Max. За них списываются не сообщения, а кредиты:
столько, сколько стоит модель за запрос, плюс доплата за длинный чат. Кредиты покупаются в чате через окно-калькулятор.

Как включить (Панель)
---------------------
1. «Тарифы и оплата» → карточка «Ultra-модели и кредиты»:
   - «Включено»;
   - цена 1 кредита, ₽ (например 13,5 ≈ 0,15 $);
   - себестоимость 1 кредита, ₽ — покажет наценку; цену ниже себестоимости сохранить нельзя;
   - максимум за покупку (по умолчанию 10 000);
   - подарок к Max в месяц (0 — без подарка);
   - потолок длины ответа (ограничивает стоимость одного ответа, по умолчанию 8000 токенов);
   - бесплатный контекст / шаг / доплата за шаг (по умолчанию 20K токенов бесплатно, +1 кредит за каждые 10K сверх).
   «Сохранить тарифы».
2. «Модели»: у нужной модели заполните «Ultra, кр.» — сколько кредитов стоит запрос. Модель сразу становится
   доступной только на Max. Пусто или 0 — обычная модель (тарифы модели проверьте вручную).
3. Там же в карточке Ultra — ручное начисление/списание кредитов по логину, почте или ID и статистика за 30 дней.

Как это работает для клиента
----------------------------
- Окно «Ultra-кредиты»: баланс (купленные + подарок до даты), калькулятор — плавный ползунок от 1 до максимума
  (левая половина — 1…500 поштучно, правая — 500…10 000), поле для точного числа, быстрые кнопки 100/500/1000/5000/Максимум,
  сумма в ₽ считается сразу, «≈ N запросов к <модель>», выбор способа оплаты, история операций.
- Открывается: бейдж «⚡ N» в строке над полем ввода (на Max), кнопка в «Лимиты и покупки», автоматически —
  когда кредитов не хватило на запрос.
- В меню моделей у Ultra — оранжевая метка «Ultra · N кр.».
- Над полем ввода при выбранной Ultra-модели: «Ultra · этот запрос ≈ 5 кредитов (+2 за длинный чат) · на балансе 120»;
  если не хватает — красным и кнопка «пополнить».
- Списание: сначала подарочные, потом купленные. Нет ответа или обрыв в первых 200 символах — кредиты возвращаются;
  обрыв позже — возвращаются доплаты за раунды инструментов. Работает в чате и через API (/v1).
- Купленные кредиты не сгорают; без Max они просто ждут. Подарок к Max — раз в 30 дней, не копится
  (каждый месяц подарочный баланс снова равен числу из панели). Если Max закончился — подарок сгорает в срок.
- Покупка от 1 кредита, без минимума. Если платёжка не примет маленькую сумму, клиент увидит её ошибку.
  Промокоды на кредиты не действуют; покупка кредитов не тратит скидку первой покупки и не считается оплатой тарифа.

API
---
GET  /api/billing → поле ultra { on, bal, bonus, bonusUntil, price, maxBuy, monthly, ctxFree, ctxStep, ctxCredits, max }
GET  /api/billing/ultra → { ultra, history }
POST /api/pay/create { plan: "credits", qty, method }
Ошибка чата при нехватке: 402 { code: "credits", need, have }. В /v1 — ошибка quota с текстом.
Панель: GET /api/admin/ultra/stats, POST /api/admin/ultra/grant { who, n }.
