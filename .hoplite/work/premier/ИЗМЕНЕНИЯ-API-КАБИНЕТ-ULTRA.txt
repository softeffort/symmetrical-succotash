КАБИНЕТ РАЗРАБОТЧИКА: ULTRA-МОДЕЛИ И БАЛАНС КРЕДИТОВ (2026-11-18)
================================================================

Что было не так
---------------
- На странице «Модели» у всех карточек стояло «1 сообщение за запрос», в том числе у Claude (Ultra-модели). На деле запрос к ним
  списывает Ultra-кредиты (цена модели + доплата за длинный контекст), а не сообщения.
- В боковой панели («Сегодня 1 из 10 000 · ULTRA») были только сообщения; баланс Ultra-кредитов в кабинете не был виден нигде.

Что изменилось для клиента
--------------------------
- Карточка Ultra-модели: «N кредитов за запрос», метка «Ultra», строка про доплату («Длинный контекст: +1 за каждые 10 тыс. токенов
  сверх 20 тыс.» — числа из панели). Если тариф без Ultra — подпись «Доступна на тарифе Ultra»; если Ultra выключен в панели — «Ultra-модели
  сейчас выключены». Обычные модели — по-прежнему вес в сообщениях.
- Боковая панель и обзор: блок «Ultra-кредиты» — всего, из них «Тарифные: N (сгорают в 00:00 по Москве)» и «Купленные: N (не сгорают)»,
  кнопка «Пополнить». На тарифе без Ultra — «Ultra-модели — на тарифе Ultra» (или «Купленные кредиты ждут тарифа Ultra»).
  Блок скрыт, если Ultra выключен и кредитов нет.
- Кнопка «Пополнить» ведёт на /chat?ultra=1: чат (RU и EN) сам открывает окно «Ultra-кредиты» и убирает параметр из адреса
  (public/js/21-ultra.js, версия скрипта в chat.html поднята до v=6).
- Виджет сообщений: лимит null / 0 / не число — «Без лимита», «из 0» не рисуется; у «безлимита» с защитным потолком (fair) подпись
  «Дневной потолок «безлимита»» вместо «Общий лимит с чатом».
- Мастер подключения и песочница: у Ultra-моделей цена в кредитах; «выгоднее всего» не выбирает Ultra-модель (ключ без разрешения её не вызовет).
- Раздел «Документация → Списание» дополнен про кредиты.

API (поля добавлены, старые не менялись)
-----------------------------------------
GET /api/dev/state:
  models[]   + ultra (bool), ultra_credits (число кредитов за запрос или null); weight, available, plan_hint — как раньше
  usage      + unlimited (тариф без лимита сообщений), fair (лимит — защитный потолок безлимита)
  credits    { total, plan, bought, resets_at, daily, access, on, price, max_buy, ctx_free, ctx_step, ctx_credits, plan_hint }
             plan — кредиты тарифа (сгорают в конце суток по Москве), bought — купленные, resets_at — когда сгорят тарифные (null, если их нет)
GET /api/dev/usage: + credits (тот же объект)
/v1/models не менялся (формат OpenAI/Anthropic).
